# Research Skill

## Purpose
This skill provides capabilities for conducting deep technical research, codebase exploration, and information gathering to support kernel development tasks.

## Key Rules from Architecture Proposal
- **Systematic Exploration**: Always start with broad context gathering before diving into specifics
- **Source Verification**: Cross-reference findings across multiple authoritative sources
- **Documentation First**: Prioritize official documentation, specifications, and source code over secondary sources
- **Reproducible Results**: Document search queries, sources, and methodology for verification
- **Scope Management**: Define clear research boundaries to prevent scope creep

## Trigger Conditions
- User asks for technical deep-dives on kernel concepts
- Need to understand unfamiliar subsystems or APIs
- Investigating bug root causes requiring historical context
- Evaluating design alternatives for new features

## Expected Outputs
- Structured research reports with citations
- Annotated code references with line numbers
- Comparative analysis tables for design decisions
- Actionable recommendations with trade-offs
